### Project Description:

Our project will simulate smart electronic appliances and devices in a smart home environment. The program will be applicable to any and all users so long as they’re familiar with the featured types of appliances in the program. The system will be composed of different kinds of home appliances which can be instantiated and customized by the user, and each type of appliance will have its own set of features, properties and executable functions. There will be one parent class for all smart appliances, containing attributes such as ID, name, and status (on or off). The main planned subclasses will be a television class, a lights class, and a fridge class, which will all have their own methods to match the type of appliance. These methods include but are not limited to controlling the temperature, changing the channel, and adjusting brightness.
